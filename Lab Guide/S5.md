## Scenario 5 — Reusable System Administration Toolkit

### Task 5: Develop a Reusable System Administration Toolkit

#### Scenario

The System Administration team requires reusable shell functions that can be incorporated into future automation and troubleshooting projects.

#### Objectives

* Create a Bash script named **system-tools.sh**.
* Create a function named:

```bash
get_system_info()
```

The function must display:

* Hostname
* Operating System
* Current User

* Create a function named:

```bash
get_disk_status()
```

The function must display:

* Filesystem
* Total Space
* Available Space

#### Additional Requirements

* Call both functions within the script.
* Display results on screen.
* Save the combined output to:

```text
/ home/labuser/reports/SystemInfoReport.txt
```

* Functions should accept parameters where applicable.
* Functions should be reusable and independently callable.
