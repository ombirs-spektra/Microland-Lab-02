## Lab Completion Criteria

To successfully complete this lab, students should demonstrate:

* Use of environment variables within Bash scripts.
* Automated Linux user creation and management.
* Disk monitoring and alert generation.
* Automated backup creation and reporting.
* Development and use of reusable shell functions.
* Report generation and operational logging.
* Basic validation and error handling within shell scripts.

All tasks must be completed using Bash shell scripting and standard Linux administrative utilities. Scripts must execute successfully and generate the required reports and log files.
