## Scenario 1 — Environment Reporting and Inventory Collection

### Task 1: Create an Environment Reporting Utility

#### Scenario

The Operations team requires a utility that can collect server environment information and generate reports for troubleshooting, inventory tracking, and operational audits.

#### Objectives

* Create a Bash script named **env-report.sh**.
* Retrieve the following information using environment variables:
  * Current username
  * Hostname
  * Home directory
  * Current shell
  * Current working directory
* Create the directory **/home/labuser/reports** if it does not already exist.
* Generate a report named **/home/labuser/reports/EnvironmentReport.txt**.
* Store all collected information within the report file.
