## Scenario 3 — Disk Utilization Monitoring and Alerting

### Task 3: Implement Disk Monitoring and Alerting

#### Overview

The Operations team requires a monitoring utility capable of identifying low disk space conditions and maintaining historical disk usage logs.

#### Objectives

* Create a Bash script named **disk-alert.sh**.
* Monitor the root filesystem (**/**).
* Calculate and display:
  * Total disk size
  * Available free space
  * Free space percentage
* Generate the following alert when free space falls below 20%:

```text
WARNING: Disk space below threshold.
```

* Display a healthy status message when sufficient free space is available.
* Generate a log file named **/home/labuser/reports/DiskUsageLog.txt**.

#### Log Requirements

The log must contain:

* Filesystem
* Total Size (GB)
* Free Space (GB)
* Free Percentage
* Status
* Date and Time
