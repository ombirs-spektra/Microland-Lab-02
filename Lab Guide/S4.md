## Scenario 4 — Automated Backup Operations

### Task 4: Implement an Automated Backup Solution

#### Scenario

The Support team requires a repeatable backup process for protecting critical business data and maintaining backup records.

#### Objectives

* Create a Bash script named **backup-folder.sh**.
* Backup data from:

```text
/home/labuser/LabData
```

* Store backup archives in:

```text
/home/labuser/backups
```

* Create timestamped backup archives using the following format:

```text
yyyyMMdd-HHmmss
```

* Create compressed backup archives using tar and gzip.
* Display a success message upon completion.
* Generate a report named **/home/labuser/reports/BackupLog.txt**.

#### Report Requirements

The report must contain:

* Backup Time
* Source Path
* Backup File Name
* Backup Size

> Note: Create at least three sample files inside `/home/labuser/LabData` before executing the backup script.
